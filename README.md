Experiments of tweakable white-box scheme with hardware-binding based on PUF and tweakable block cipher:  
The first platform (server) is Custom-built Server, with Intel Core i7-14700KF @ 3.4 GHz, 32 GB DDR4 RAM, and Ubuntu 24.04.1 LTS (WSL2).  
The second (client) is Raspberry Pi 5, with ARM Cortex-A76 @ 2.4 GHz, 8 GB LPDDR4X SDRAM, and Linux raspberrypi 6.12.25.
